# 30 天掌握 Linux 网络子系统

这是一条以动手实践和实验为驱动、深入 Linux 内核网络协议栈的学习路径。你将阅读内核源码，使用 ftrace/perf/bpftrace 插桩，修改 sysctl，并观察系统行为。内容已在内核 7.1 上验证。

## 到第30天你将掌握什么

- 一个数据包如何逐层穿过内核，从线路到达用户空间，再从用户空间返回线路。
- 不仅知道 `sk_buff`、`net_device`、`sock`、`dst_entry`、`fib_table`、`nf_conntrack` 等数据结构的名称，还能找到它们的具体行号。
- TCP 状态机，以及 Linux 的拥塞控制算法（CUBIC、BBR 等）如何接入框架。
- Netfilter、nftables 和 conntrack——现代数据包过滤三件套。
- 流量控制：qdisc、类和 fq_codel。
- 现代特性：kTLS、MPTCP、io_uring 网络和 drop_monitor。

| 阶段 | 天数 | 重点 |

## 如何使用本书

每天的内容约需 75–90 分钟。大多数天大致遵循以下结构（并非每天都会出现所有部分）：

1. **今日概念**——将介绍哪些新结构和路径。
2. **内核阅读内容**——内核源码检出目录中的具体文件和函数。行号已针对内核 7.1 验证。
3. **今日实验**——通过跟踪、修改或观察什么来了解这些结构的实际运行方式。
4. **尝试破坏什么**——用于展示效果的 sysctl 或配置（有时会并入实验部分）。
5. **要点回顾**。
6. **检查问题**。

实验主要使用 ftrace、perf 和 bpftrace 进行观测。完成这些实验不要求你会*编写* BPF 程序，只需使用单行命令和现有工具。

## 提示：保存 sysctl 快照

有些实验会调整 sysctl。开始前先保存快照：

```bash
sudo sysctl -a > sysctl.snapshot.$(date +%Y%m%d)
```

这样每天结束时就能通过 `diff` 对照并恢复到已知正常状态。
