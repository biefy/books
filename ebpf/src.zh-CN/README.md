# 30 天 eBPF 实战

这是一条以动手实践和实验为核心的学习路径，带你掌握 Linux 7.1 上的现代 eBPF。全书采用 Head First 风格编写，并配有渲染后的图示。

## 到第30天你将掌握什么

- BPF 程序如何编译、验证、JIT 编译并挂载。
- 验证器的类型系统，以及如何熟练读懂它的拒绝信息。
- CO-RE、BTF，以及 libbpf 如何在加载时重定位字段偏移量。
- 使用 fentry/fexit/tracepoints/uprobes 进行跟踪；捕获栈；生成火焰图。
- 网络 BPF：XDP、tc/tcx、AF_XDP、cgroup_skb、sockops。
- 现代原语：kfuncs、kptrs、struct_ops、BTF 探索。
- 前沿领域：sched_ext（由 BPF 定义的内核调度器）。

## 阶段

| 阶段 | 天数 | 重点 |
|-------|------|-------|
| **1：基础** | 1–5 | libbpf 工作流、CO-RE、验证器直觉 |
| **2：跟踪** | 6–13 | fentry/fexit、跟踪点、栈、uprobes、可睡眠程序 |
| **3：网络 BPF** | 14–19 | XDP、tc、tcx、AF_XDP、cgroup/sockops |
| **4：现代原语** | 20–24 | kfuncs、kptrs、struct_ops、BTF |
| **5：前沿领域 + 综合项目** | 25–30 | sched_ext、综合项目 |

## 如何使用本书

每天约需 75–90 分钟。内容结构如下：

1. **今日概念**——在任何代码使用新原语之前，先说明它们是什么。
2. **实验**——可运行的代码，以及逐行讲解。
3. **按顺序进行破坏实验**——通过刻意制造最有教学价值的错误来学习。
4. **内核源码阅读**——你的内核检出目录中需要查看的具体文件和函数。
5. **要点回顾**——睡前可以快速复习的简明总结。
6. **检查问题**——第二天早晨用于回忆的一个问题。

最重要的一步是**刻意破坏**。不要跳过。每个实验只需花五分钟直面问题，却能让你日后少走数周弯路。

## 实验源码和前置条件

请从[实验环境](lab-environment.md)页面开始。该页面定义了 Linux 工具链、锁定版本的递归依赖、锁定的 Linux v7.1 源码、权限边界，以及各后端的构建命令。

每个已发布条目在 `ebpf/labs/` 下都有一份实验记录。第1–21天、第24天和参考综合项目使用已检入仓库的源码；章节中的主要代码清单直接引入 CI 实际编译的同一批文件。第22天和第 25/27 天封装指定的上游 v7.1 目标；第 23/26 天则包含由本仓库完整维护、基于这棵锁定源码树构建的衍生版本。`make -C ebpf/labs check-coverage` 可防止某一章节在无人察觉时脱离这项约定。

## 风格说明

- **Head First 语气。** 使用对话式的第二人称叙述，并让验证器作为反复登场的角色。
- **真正的图示。** 每个适合可视化的概念都配有渲染后的 PNG。
- **不使用 bcc。** 只使用现代 libbpf + CO-RE。

## 配套书籍

本书假定你已经了解内核网络协议栈。如果尚不了解，请先阅读 [Linux 网络子系统一书](../../linux-net/zh-CN/)——其中涵盖 `sk_buff`、RX/TX 路径、netfilter，以及 BPF 程序所挂载到的其他组成部分。
